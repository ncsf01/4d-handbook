# 4D Handbook

Promotional website (in Portuguese) for **The Beginner's 4D Handbook: A Roleplay Style Primer**, by Mike Melnick and James Bacon, a guide to the 4D roleplaying style, which focuses on getting into character and staying there as long as possible.

🔗 **Live site:** https://ncsf01.github.io/4d-handbook/

## About

Built as a web development assignment at Fatec (Software Development, 1st semester).

This is the second version of the project, rewritten with Bootstrap. The first version, made with plain HTML and CSS, is available at [4d-handbook-v1](https://github.com/ncsf01/4d-handbook-v1).

## Pages

- **Home**: introduction to the 4D style, a quote carousel and its three core ideas
- **About**: the origin of the style, the 5 practical pillars of the 4D player and the handbook's goals
- **Contact**: community links (Discord and YouTube channels) and a contact form (visual only, not functional)
